# SnapAI v0.1 — Product Requirements Document

**版本：** v0.1
**状态：** 开发前
**产品类型：** Windows 桌面 AI 工具
**目标用户：** 首期仅自己
**核心目标：** 解决电脑上遇到无法复制的文字时，需要截图并发送给 AI 才能提取文字的问题。

------

## 1. 产品概述

SnapAI 是一个运行在 Windows 电脑上的轻量级 AI 屏幕文字提取工具。

用户可以通过全局快捷键快速唤起屏幕区域选择工具，框选需要提取的内容后，SnapAI 将截图发送给 Vision AI 进行文字识别，并将识别结果自动写入系统剪贴板。

用户无需手动打开截图工具、保存图片、上传 AI、复制识别结果。

### 核心体验

> **快捷键 → 框选 → AI识别 → 自动复制 → Ctrl+V**

# 3. 用户痛点

在日常电脑使用过程中，经常会遇到无法直接复制的文字，例如：

- 网页中禁止选择的文字
- 图片中的文字
- 软件界面中的文字
- 错误提示
- 图片形式的代码
- PDF / 截图中的文字
- 其他无法直接复制的内容

目前解决方式通常是：

```text
截图
 ↓
打开 AI
 ↓
上传图片
 ↓
发送请求
 ↓
AI 提取文字
 ↓
手动复制
```

这个过程存在明显的操作成本。

SnapAI 希望将其压缩为：

```text
Ctrl + Shift + X
 ↓
框选
 ↓
自动识别
 ↓
自动进入剪贴板
```

------

# 4. 产品目标

## 4.1 核心目标

实现一个稳定、快速的屏幕文字提取闭环。

用户可以在几秒内完成：

> **屏幕任意区域 → 纯文本**

------

## 4.2 非目标

v0.1 暂时不解决：

- 翻译
- 总结

- 错误分析

- 多用户
- 商业化

这些作为未来版本的潜在方向记录，但不进入 v0.1 开发范围。

```text

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓
```

# 6. 输入

### 用户输入

屏幕区域截图。

### 输入来源

用户通过鼠标在屏幕上框选一个矩形区域。

### 输入示例

```text
┌──────────────────────────┐
│ Error: Connection failed │
│ Please check your config │
└──────────────────────────┘
```

用户框选该区域。

SnapAI 获取对应图片。

------

# 7. 处理流程

## 7.1 全局快捷键

默认快捷键：

```text
Ctrl + Shift + X
```

程序在后台运行并监听该快捷键。

触发后进入屏幕区域选择状态。

------

## 7.2 区域选择

程序显示覆盖整个屏幕的透明选择层。

用户：

```text
鼠标按下
 ↓
拖动
 ↓
形成矩形区域
 ↓
鼠标释放
```

程序获得：

```text
x
y
width
height
```

等区域信息。

------

## 7.3 屏幕截图

根据用户选择的区域进行截图。

截图仅用于当前识别流程。

v0.1 默认不永久保存用户截图。

------

## 7.4 Vision AI

将截图发送至支持视觉输入的 AI 模型。

AI 的主要任务：

> **准确提取图片中的文字，并尽可能保持原始文本内容。**

v0.1 输出目标为：

**纯文本。**

------

## 7.5 剪贴板

AI 返回文本后：

```text
Vision AI
   ↓
Text
   ↓
System Clipboard
```

用户可以直接：

```text
Ctrl + V
```

使用结果。

------

# 8. 输出

v0.1 唯一核心输出：

> **纯文本**

例如：

输入图片：

```text

```

输出：

```text
Error: Failed to connect to server.
```

并自动进入系统剪贴板。

# 14. 性能要求

核心性能指标：

> **从用户按下快捷键，到识别文字进入剪贴板，目标时间 < 5 秒。**

这里的时间包含：

```text
快捷键触发
+
区域选择
+
截图
+
AI 请求
+
结果处理
+
写入剪贴板
```

------

# 15. 准确性要求

v0.1 暂时不设置严格的数学准确率指标。

但必须保证：

### 正常清晰文字

能够稳定识别。

测试内容至少包括：

- 中文
- 英文
- 中英文混合
- 数字
- 标点符号
- 普通网页文字
- 软件界面文字
- 错误信息
- 代码

后续建立测试数据集后，再定义具体准确率指标。

------

# 16. 稳定性要求

在正常使用情况下：

- 快捷键能够稳定触发
- 区域选择不会导致程序崩溃
- AI 请求失败时程序不会退出
- 网络异常时程序能够给出提示
- 多次连续使用不会导致程序异常
- 剪贴板能够正常写入结果

------

# 17. 隐私要求

由于 v0.1 使用 Vision AI：

> **用户框选的屏幕内容可能会被发送至第三方 AI 服务。**

因此：

- 默认不永久保存截图
- API Key 不进入 Git
- 不主动保存用户识别内容
- README 中明确说明图片可能发送至第三方 AI 服务

后续如果增加本地 OCR，可以提供：

> **Local / Private Mode**

------

# 21. AI 辅助开发原则

本项目使用 Codex 辅助开发。

AI 的职责：

- 编写重复性代码
- 实现明确的技术任务
- 辅助 Debug
- 编写测试
- 提供代码解释
- 辅助重构

人的职责：

- 定义需求
- 技术决策
- 架构设计
- 验收结果
- 理解关键代码
- 测试
- 判断是否真正解决问题

原则：

> **AI 可以写代码，但不能替代对系统的理解。**
